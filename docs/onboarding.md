# 처음 오셨다면

이 문서만 따라 하면 첫 이슈를 시작해서 PR까지 올릴 수 있어요. 막히면 "막힌 화면 + 메시지"를 디스코드에 올려 주세요.

## 1. 설치 (처음 한 번)

1. **Node.js** LTS: https://nodejs.org → 설치 후 터미널에서 `node -v`가 나오면 성공
2. **Git**: https://git-scm.com/downloads
3. **Claude Code**: 설치하고 로그인
4. **GitHub**: 메일로 온 EliceAi 조직 초대를 수락 (7일 지나면 만료돼요)
5. **GitHub CLI**: https://cli.github.com → 설치 후 `gh auth login` (Claude가 이슈·PR을 다룰 때 써요)

## 2. 첫 실행

```bash
git clone https://github.com/EliceAi/docAi-fe.git
cd docAi-fe
npm install
```

`.env.example` 파일을 복사해서 이름을 `.env.local`로 바꿔요. 내용은 그대로 둬요.

```bash
npm run dev
```

- 브라우저에서 http://localhost:5173 → 앱
- http://localhost:5173/dev/boards → 와이어프레임 보드 모아 보기 (진행률, 칸을 누르면 크게 보기)
- 터미널을 닫으면 서버도 꺼져요. 작업하는 동안 켜 두세요.

## 3. 일하는 방법: 말 세 마디

`docAi-fe` 폴더에서 Claude Code를 켜고 이렇게 말하면 돼요. Claude가 마지막에 다음에 할 말을 알려 줘요.

| 이렇게 말하면 | Claude가 하는 일 |
|---|---|
| **"15번 이슈 할게요"** | 이슈 읽기 → 브랜치 만들기 → 계획 보여 주기 → 승인하면 보드를 하나씩 옮기고 이슈 체크 |
| **"확인해줘"** | 빌드, 와이어프레임과 비교, 규칙·수정 범위 검사 → 빠진 것 알려 주기 |
| **"PR 올려줘"** | 커밋 → push → PR 작성 → 주소 알려 주기 |

그 밖에 쓸 수 있는 말:
- "커밋해줘": 중간에 저장하고 싶을 때
- "PR 의견 반영해줘": 팀원이 PR에 의견을 남겼을 때
- "N번 PR 봐줘": 팀원 PR을 확인할 때 (승인 버튼은 직접 눌러요)

## 4. 저장소에서 저절로 일어나는 일

| 언제 | 무슨 일 | 나는 뭘 하면 되나 |
|---|---|---|
| `dev`·`main`에 직접 올리려 하면 | 막혀요 | 항상 작업 브랜치 → PR (Claude가 알아서 해요) |
| PR을 올리면 | 빌드 검사가 자동으로 돌고, 디스코드에 "리뷰 요청" 알림 | 빌드가 빨간불이면 "빌드 실패 고쳐줘" |
| 팀원 1명이 승인하면 | 디스코드에 "머지 가능" 알림 | PR 화면에서 **Merge pull request** |
| 머지되면 | `Closes #N` 이슈가 자동으로 닫히고, GitHub의 작업 브랜치가 자동으로 지워지고, 디스코드에 "머지" 알림 | "다음 이슈 할게요" (dev 받기·로컬 브랜치 정리는 Claude가 해요) |

## 5. 휴대폰으로 보기 (카메라·촬영 화면을 볼 때만)

평소에는 PC 브라우저(`npm run dev`)로 충분해요.

1. PC와 휴대폰을 **같은 와이파이**에 연결해요.
2. 터미널에서 `npm run dev:phone`을 실행하고 켜 둬요.
3. 터미널에 나온 `Network:` 주소를 휴대폰 브라우저에 입력해요. 예: `https://192.168.45.29:5173` (숫자는 PC마다 달라요, 포트는 5173)
4. "연결이 비공개로 설정되어 있지 않습니다"가 나오면 **고급 → 계속 진행**. 내 PC에서 띄운 개발 서버라 괜찮아요.
5. 카메라 권한을 물으면 허용해요.

안 열릴 때:
- 터미널이 꺼져 있다 → 2번부터 다시
- `http://`로 입력했다 → 꼭 `https://`
- 학교·회사 와이파이 → 기기끼리 접속을 막기도 해요. 휴대폰 핫스팟에 PC를 연결해 보세요
- Windows 방화벽 창이 뜨면 → "개인 네트워크" 허용

## 6. 꼭 기억할 것

- 와이어프레임 문구는 바꾸지 않아요. 바꾸고 싶으면 먼저 물어봐요.
- 내 이슈 폴더(`src/pages/<기능>/`, `src/api/<기능>.ts`, `src/api/mocks/<기능>.ts`) 밖의 파일은 고치기 전에 물어봐요. Claude도 멈추고 물어봐요.
- 새 라이브러리는 설치하지 않아요.
- `.env.local`은 올리지 않아요(이미 막혀 있어요).
